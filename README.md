# Ejercicios de Programación en Java (DAW)

Repositorio con ejercicios básicos de programación en Java realizados durante el ciclo de Desarrollo de Aplicaciones Web (DAW). El objetivo es demostrar el dominio de los fundamentos del lenguaje.

## 🛠️ Tecnologías y Herramientas
*   **Lenguaje:** Java (JDK 17)
*   **IDE:** Apache NetBeans
*   **Entorno:** Consola de texto

## 🎯 Conceptos Aplicados

### 1. `Ejercicio1.java` (Cálculo de expresiones físicas/matemáticas)
*   **Entrada de datos:** Uso de la clase `Scanner` para leer datos por teclado.
*   **Tipos de datos:** Uso de variables enteras (`int`), de coma flotante (`float`, `double`) y constantes.
*   **Casting:** Conversión explícita de `float` a `int` y conversión implícita de `int` a `double`.
*   **Cálculos:** Implementación de fórmulas matemáticas (cálculo del área de un círculo, fuerza peso) y aproximación de Pi usando la serie de Leibniz.
*   **Enumeraciones:** Uso de un `enum` para almacenar los nombres de las expresiones.

### 2. `Ejercicio2.java` (Uso de cadenas de caracteres)
*   **Manejo de Strings:** Uso de métodos nativos de Java para manipular cadenas: `trim()`, `substring()`, `replace()`, `length()`, `charAt()` y `contains()`.
*   **Lógica de caracteres:** Comprobación de si el último carácter de una cadena es una consonante mediante comparaciones lógicas (sin usar expresiones regulares).
*   **Operador ternario:** Uso de `? :` para mostrar "SI" o "NO" en la salida.

## 🚀 Cómo ejecutar los ejercicios
1. Clona el repositorio y abre los archivos en tu IDE de Java (NetBeans, IntelliJ o Eclipse).
2. Ejecuta cada clase (`Ejercicio1` o `Ejercicio2`) como una aplicación Java.
3. Sigue las instrucciones que aparecerán en la consola para introducir los datos.
