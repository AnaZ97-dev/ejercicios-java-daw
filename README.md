# Ejercicios de Programación en Java (DAW)

Repositorio con ejercicios de programación en Java realizados durante el ciclo de Desarrollo de Aplicaciones Web (DAW). El objetivo es demostrar el dominio de los fundamentos del lenguaje y la lógica de programación.

## 🛠️ Tecnologías y Herramientas
*   **Lenguaje:** Java (JDK 17)
*   **IDE:** Apache NetBeans
*   **Entorno:** Consola de texto

## 🎯 Ejercicios Incluidos

### 1. `Ejercicio1.java` (Cálculo de expresiones físicas/matemáticas)
*   **Conceptos:** Entrada de datos con `Scanner`, tipos de datos (`int`, `float`, `double`), casting, cálculos matemáticos y uso de `enum`.
*   **Descripción:** Programa que calcula expresiones físicas y matemáticas (área de un círculo, fuerza peso) y aproxima el valor de Pi.

### 2. `Ejercicio2.java` (Uso de cadenas de caracteres)
*   **Conceptos:** Manipulación de `String` (`trim`, `substring`, `replace`, `length`, `charAt`, `contains`), operador ternario.
*   **Descripción:** Programa que realiza diversas operaciones sobre una cadena de texto y comprueba si termina en consonante.

### 3. `Ejercicio2_MaquinaExpendedora.java` (Máquina Expendedora)
*   **Conceptos:** Estructuras de control (`switch`, `if-else`), validación de datos, cálculo de cambio con decimales.
*   **Descripción:** Simulación de una máquina expendedora de bebidas. El usuario selecciona una bebida, introduce dinero y el programa calcula el cambio o indica si el dinero es insuficiente.

### 4. `Ejercicio3_FormacionRomana.java` (Formación Romana)
*   **Conceptos:** Bucles `while` (validación) y `for` anidados, uso de `Math.sqrt()`, lógica de formaciones militares.
*   **Descripción:** Programa que simula formaciones militares romanas (en línea o en cuadrado) a partir de un número de soldados introducido por el usuario.

## 🚀 Cómo ejecutar los ejercicios
1. Clona el repositorio y abre los archivos en tu IDE de Java (NetBeans, IntelliJ o Eclipse).
2. Ejecuta cada clase como una aplicación Java.
3. Sigue las instrucciones que aparecerán en la consola para introducir los datos.
